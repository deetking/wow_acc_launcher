## WoW Nemesis Launcher 1.12

Stiahni **WoW_Nemesis_Launcher_v1.12_release.zip** z príloh tohto vydania.
Rozbaľ celý ZIP a spusti **WoW_Nemesis_Launcher_v1.12.exe**.
Priečinok `_internal` musí zostať vedľa EXE. Python ani inštalácia nie sú potrebné.

- Windows 64-bit; vlastná inštalácia WoW 2.4.3.
- Uložené účty a automatické prihlásenie.
- Viac autocastov pre každý účet s vlastnými intervalmi.
- Nastaviteľná spoločná skratka na zapnutie a vypnutie autocastov spustených účtov.
- Voliteľné Anti-AFK, pôvodný toolbar a fantasy pozadie.

Účty sa ukladajú lokálne v `%APPDATA%\WoWNemesisLauncher`; release neobsahuje prihlasovacie údaje.
Pri aktualizácii rozbaľ vydanie do nového priečinka. Existujúce nastavenia sa načítajú automaticky.

Priložený `.sha256` obsahuje kontrolný súčet ZIP-u. GitHub položky „Source code“ sú zdrojové súbory pre vývojárov.
